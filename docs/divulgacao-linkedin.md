# Post LinkedIn — Despensa Inteligente

🧠 **Despensa Inteligente — Zero Desperdício • 100% Offline**

Quanto dinheiro você já jogou fora em comida vencida no fundo da geladeira? Foi desse incômodo que nasceu meu app Android: uma despensa de bolso que avisa **antes** de vencer.

📱 **O que ele faz:**
✅ Controle de Frescor — semáforo Frescos / Atenção / Vencidos com valor em R$ do estoque
✅ Leitor de código de barras (ML Kit) com catálogo offline de produtos
✅ Lista de Compras + modo supermercado com carrinho e entrada automática no estoque
✅ Inventário físico com contagem, comparação contado × lançado e compartilhamento
✅ Aba Economia com histórico e exportação da lista via WhatsApp
✅ 100% offline — seus dados ficam no aparelho (Room + DataStore)

🛠️ **Stack:** Kotlin + Jetpack Compose + CameraX + ML Kit, arquitetura MVVM com Hilt, testes unitários (140+ e contando) e fluxo Git com PRs revisadas.
